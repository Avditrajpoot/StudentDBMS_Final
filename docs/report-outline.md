# Project Report Outline

Use this as the report structure required by the VITyarthi instructions.

1. Cover Page — project title, student name, registration number, course, faculty.
2. Introduction — context and purpose.
3. Problem Statement — see `statement.md`.
4. Functional Requirements — Student CRUD, Course Management, Enrollment, Reporting.
5. Non-functional Requirements — performance, security, usability, reliability, maintainability, error handling.
6. System Architecture — see `docs/design.md`.
7. Design Diagrams — use case, workflow, sequence, class, ER.
8. Design Decisions & Rationale — Java 17, JDBC, MySQL, layered DAO structure, relational constraints.
9. Implementation Details — explain packages and important SQL operations.
10. Screenshots / Results — add screenshots of menu, CRUD, enrollment and reports.
11. Testing Approach — run `mvn clean test`; add manual database test cases.
12. Challenges Faced — document actual issues encountered during development.
13. Learnings & Key Takeaways — JDBC, SQL, normalization/relationships, validation and modular Java.
14. Future Enhancements — GUI/web UI, authentication/roles, attendance, GPA analytics, export to CSV/PDF.
15. References — Java/JDBC/MySQL/Maven documentation and course material.
